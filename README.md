PlayCaller provides an AI‑driven fantasy sports platform that connects to major fantasy leagues (Sleeper, ESPN, Yahoo) and offers real‑time injury alerts, lineup optimization, waiver bidding, and trade analysis across NFL, MLB, NBA, NHL, golf and soccer. Users can start for free with no credit card, access a sandbox API, and integrate the validated sports intelligence API (120 endpoints) into their own apps.

**Areas:** Sports · Fantasy · API · Data · AI

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).

The artifacts are published on [APIs.io](https://apis.io), not in this repository. This repository is the public record for PlayCaller: the place to say something is wrong, missing or out of date, and to ask for a re-score or a removal.
